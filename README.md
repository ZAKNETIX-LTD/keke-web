# Fastigo Admin

Vite + React ops console for Fastigo.

## Run

```bash
cd adminapp
npm install
npm run dev
```

Open http://localhost:5173

Login: `admin@trigo.app` / `Admin123!`

Set `VITE_API_URL` in `.env` to your backend (default `http://localhost:34567`).
Set `VITE_GOOGLE_MAPS_API_KEY` for trip maps (same key as the mobile apps).
